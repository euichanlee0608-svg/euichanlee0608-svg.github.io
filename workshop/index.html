Safety rails on my own automation개인 자동화의 안전장치

AI agents and several bots run on a Mac mini at home. Before letting them do more, I made sure they could not do damage quietly.집의 맥 미니에서 AI 에이전트와 봇 여러 개가 돌아갑니다. 일을 더 맡기기 전에, 조용히 사고를 내지 못하게 하는 장치부터 만들었습니다.

  • Three tiers of approval승인 3단계 Every command an agent runs is sorted into safe, needs my approval, or blocked, by one rules file shared by everything.에이전트가 실행하는 모든 명령을 안전·승인 필요·차단으로 판정하며, 판정 규칙은 한 파일에만 둡니다.
  • A snapshot before every change바꾸기 전에 스냅샷 Fully automatic mode exists only because files are snapshotted before they change, and one command rolls them back.완전 자동 모드는 파일을 바꾸기 전에 스냅샷을 뜨고 명령 하나로 되돌릴 수 있기 때문에 허용합니다.
  • Gates before restart재기동 전 게이트 Bot code restarts only after a regression gate, including tests that push real messages through handlers with outside calls sealed off.봇 코드는 회귀 테스트를 통과해야 재기동되며, 외부 호출을 막은 채 실제 메시지를 흘려 보는 테스트를 포함합니다.
  • No quiet baselines기준선은 사람이 Research repos never update their reference results automatically, only verified commits get pushed, and numbers an LLM writes are checked against the source in a second pass.연구 레포의 기준 결과는 자동으로 갱신하지 않고, 검증을 통과한 커밋만 푸시하며, LLM이 쓴 수치는 별도 호출로 원문과 대조합니다.
  • Read-only by default기본은 읽기 전용 The mail bot reads but never sends, calendar entries wait for a tap, and every web app's notifications have their own off switch.메일 봇은 읽기만 하고, 캘린더 등록은 버튼 승인을 거치며, 웹앱 알림은 앱마다 끄는 스위치가 있습니다.
  • Heartbeats and a map하트비트와 지도 Each bot writes a heartbeat so a dead thread restarts the process, and a checker compares the map of the whole setup with what is actually running.봇마다 하트비트를 남겨 죽은 스레드를 감지하면 프로세스를 재시작하고, 전체 구성 지도와 실제 환경이 어긋나면 검사기가 잡습니다.
