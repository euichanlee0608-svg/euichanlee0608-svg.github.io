Safety rails on my own automation개인 자동화의 안전장치

AI agents and bots run on a Mac mini at home. Before giving them more to do, I made sure they could not break things quietly.집 맥 미니에서 AI 에이전트와 봇이 돌아갑니다. 일을 더 맡기기 전에, 몰래 사고를 칠 수 없게 막는 장치부터 만들었습니다.

  • Three approval tiers승인 3단계Each agent command is safe, needs my OK, or blocked, by one shared rules file.에이전트 명령은 하나의 규칙 파일로 안전·승인 필요·차단을 판정합니다.
  • Snapshot first스냅샷 먼저Full auto mode is allowed only because files are snapshotted before every change.파일을 바꾸기 전에 스냅샷을 뜨기 때문에 완전 자동 모드를 허용합니다.
  • Gate before restart재기동 전 게이트Bots restart only after regression tests that push real messages through sealed handlers.외부 호출을 막고 실제 메시지를 흘려 보는 회귀 테스트를 통과해야 봇이 재기동됩니다.
  • Humans set baselines기준선은 사람이Research results never update their own reference, and LLM-written numbers are checked against the source.연구 기준 결과는 자동으로 갱신하지 않고, LLM이 쓴 수치는 원문과 대조합니다.
  • Read-only by default기본은 읽기 전용The mail bot never sends, calendar entries wait for a tap, each app's alerts have an off switch.메일 봇은 보내지 않고, 일정 등록은 승인을 거치며, 앱마다 알림을 끄는 스위치가 있습니다.
  • Heartbeats and a map하트비트와 지도A dead bot thread restarts the process, and a checker compares the setup map with what is running.봇 스레드가 죽으면 프로세스를 재시작하고, 구성 지도와 실제 환경이 어긋나면 검사기가 잡습니다.
