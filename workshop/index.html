When my bots broke봇이 사고 친 날들

AI agents and bots run a good part of my own work on a Mac mini at home. None of the guards around them were planned up front. Each one is there because something went wrong first.집 맥 미니에서 AI 에이전트와 봇이 제 일의 상당 부분을 돌립니다. 안전장치는 미리 설계한 게 아닙니다. 전부 한 번씩 사고가 난 뒤에 생겼습니다.

  1. All green, still broken점검은 전부 정상, 실제로는 고장

    The health check said every part was fine while four bugs reached me. One feature was grabbing every photo I sent and running a paid model on it.점검표는 전부 정상이라고 했는데 버그 네 개가 그대로 나왔습니다. 한 기능은 제가 보내는 사진을 전부 가로채 유료 모델에 돌리고 있었습니다.

    Now a bot restarts only after tests push real messages through its real handlers and check which one answers.이제는 실제 메시지를 실제 처리 코드에 흘려 누가 반응하는지 확인한 뒤에야 봇을 다시 켭니다.

  2. The check that called itself자기 자신을 부른 검사

    I added the test suite to the health check. The tests ran the health check, which ran the tests again, and every round sent me a Telegram report.점검에 테스트를 넣었더니, 테스트가 점검을 부르고 점검이 다시 테스트를 불렀습니다. 한 바퀴 돌 때마다 텔레그램 보고가 날아왔습니다.

    Now tests run sealed: they cannot start processes, open outside connections, or send messages.이제 테스트는 봉인된 채로 돕니다. 새 프로세스도, 외부 연결도, 메시지 전송도 막혀 있습니다.

  3. A summary that filled the gaps빈칸을 지어낸 요약

    A small local model summarizing papers named a sponsor the paper never mentioned and added a problem the authors never wrote. It read smoothly, which made it worse.논문을 요약하던 로컬 소형 모델이 원문에 없는 후원 기관을 적고, 저자가 쓰지 않은 문제를 하나 지어냈습니다. 문장이 매끄러워서 더 위험했습니다.

    Now every number and name an LLM writes is checked against the source, one line at a time, by a separate and stronger model. That pipeline was retired.이제 LLM이 쓴 수치와 이름은 더 센 모델이 따로, 한 줄씩 원문과 대조합니다. 그 요약 파이프라인은 접었습니다.

  4. Off, but not really꺼 둔 줄 알았던 에이전트

    An agent I had switched off came back at every login after a reboot and crashed in a loop for six weeks, leaving 1.8 GB of error logs. The health check showed red. Nobody looked.꺼 둔 에이전트가 재부팅 뒤 로그인할 때마다 되살아나 6주 동안 죽었다 살아나기를 반복했고, 에러 로그가 1.8GB 쌓였습니다. 점검표엔 빨간불이 떠 있었는데 아무도 안 봤습니다.

    Now switching something off also keeps it off through reboots, and one tap in the bot does both.이제 끄기는 재부팅 뒤에도 꺼진 채로 남고, 봇에서 한 번 누르면 둘 다 처리됩니다.

The rule all of this left behind: anything that changes the outside world, like sending, pushing or deleting, needs a log, an undo, or my tap first.그래서 남은 원칙 하나. 보내기·올리기·지우기처럼 바깥을 바꾸는 일은 기록, 되돌리기, 제 승인 중 하나를 먼저 갖춰야 합니다.
